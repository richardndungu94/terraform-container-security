
## File Contents Quick Reference

### Terraform Files (Root)

**main.tf** - 30 lines
- Provider configuration
- AWS region setup
- Default tags
- Random suffix generation

**variables.tf** - 120 lines
- All input variables
- Validation rules
- Default values

**outputs.tf** - 80 lines
- ECR repository URL
- Application URL
- Next steps guide

**ecr.tf** - 180 lines
- ECR repository
- Lifecycle policies
- Scan findings Lambda
- EventBridge rules

**codebuild.tf** - 90 lines
- S3 bucket for artifacts
- CodeBuild project
- Build environment
- Inline buildspec (backup)

**ecs.tf** - 200 lines
- VPC/subnets
- Security groups
- ALB + target group
- ECS cluster
- Task definition (secure)
- ECS service

**iam.tf** - 150 lines
- CodeBuild role
- ECS execution role
- ECS task role
- Lambda role
- All policies

**monitoring.tf** - 120 lines
- SNS topic
- CloudWatch alarms
- Dashboard

**security.tf** - 90 lines
- KMS key (optional)
- Security metrics
- Additional controls
- Documentation

**.gitignore** - 30 lines
- Terraform files
- Python files
- Docker files
- IDE files

**terraform.tfvars.example** - 25 lines
- All configurable values
- Comments explaining each

---

### Application Files (sample-app/)

**app.py** - 30 lines
```python
# Flask application with:
- Health check endpoint (/health)
- Main endpoint (/)
- JSON responses
```

**requirements.txt** - 3 lines
```
Flask==3.0.0
Werkzeug==3.0.1
requests==2.31.0
```

**Dockerfile** - 8 lines
```dockerfile
# INSECURE version for demo
# Shows what NOT to do:
- Uses :latest tag
- Runs as root
- No security hardening
```

**Dockerfile.secure** - 30 lines
```dockerfile
# SECURE version to actually use
# Security features:
- Specific base image version
- Non-root user (UID 1000)
- Health check
- Minimal image (slim)
```

**buildspec.yml** - 60 lines
```yaml
# CodeBuild specification
# Phases:
- pre_build: Install Trivy, login ECR
- build: Build + scan image
- post_build: Push if scan passes
```

### Scripts (scripts/)

**scan-image.sh** - 40 lines
```bash
# Local scanning script
- Installs Trivy if needed
- Scans for vulnerabilities
- Scans for secrets
- Scans for misconfigurations
```

**test-deployment.sh** - 50 lines
```bash
# Test deployed application
- Gets ALB URL from Terraform
- Waits for app to be ready
- Tests health endpoint
- Tests main endpoint
- Shows logs and metrics
```
